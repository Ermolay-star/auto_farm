# Minecraft AFK Bot

Оптимизированный бот для автоматического подключения к серверу Minecraft, выбора режима через GUI и AFK.

## Установка

```bash
npm install
```

## Настройка

Отредактируйте `config.json`:
- `host` - адрес сервера
- `port` - порт сервера
- `username` - имя бота
- `version` - версия Minecraft
- `windowTitle` - заголовок меню выбора
- `slotToClick` - номер слота для клика (0-53)

## Запуск

```bash
npm start
```

## Оптимизация

- Минимальная дистанция прорисовки (`viewDistance: 'tiny'`)
- Легкие движения камеры для анти-кика
- Минимальное использование памяти
- Отключение ненужных плагинов
